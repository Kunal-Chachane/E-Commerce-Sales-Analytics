# 📊 Global E-Commerce Sales Dashboard | Power BI

> **Transforming global e-commerce transactions into actionable business insights.**

An interactive **Power BI Business Intelligence dashboard** designed to analyze global e-commerce performance across **sales, profit, orders, quantity, products, countries, regions, customer segments, and payment methods**.

The dashboard provides an easy-to-use interface with dedicated **Overview, Geography, and Products** pages for exploring business performance from multiple perspectives.

---

## 🚀 Project Overview

This project focuses on building an interactive **E-Commerce Sales Analytics Dashboard** using Power BI.

The dashboard helps stakeholders:

- Monitor overall sales and profitability
- Track key business KPIs
- Identify top-performing countries and regions
- Analyze monthly sales and profit trends
- Compare customer segments
- Identify top-selling products
- Analyze product categories
- Understand payment method usage
- Interactively filter and explore business data

The dashboard covers global orders from **January 2023 to December 2025**.

---

# 📊 Dashboard Overview

The Power BI solution consists of three interactive pages:

| 🏠 **Overview** | Overall sales, profit, customers, orders and regional performance |

# 🧠 Business Insights

The dashboard enables analysis of several important business questions.

### 💰 Sales Performance

- Which countries generate the highest sales?
- Which regions contribute the most revenue?
- How does sales performance change over time?
- Which product categories generate the most revenue?

### 📦 Product Performance

- Which products are the top sellers?
- Which categories contribute the highest sales?
- Which products should receive greater business attention?
- How does product performance vary across markets?

### 🌍 Geographic Performance

- Which region performs best?
- Which countries are the strongest markets?
- How do different regions compare in terms of sales?

### 👥 Customer Analysis

- Which customer segment contributes the most sales?
- How do Consumer, Corporate and Home Office segments compare?
- Which customer segment generates the highest revenue?

### 💳 Payment Analysis

- Which payment method is most frequently used?
- How does payment preference vary across regions?
- Which payment methods contribute most to order volume?
